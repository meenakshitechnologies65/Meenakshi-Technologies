# Meenakshi Technologies - Frontend Architecture

This folder structures the frontend assets and presentation components for the Meenakshi Technologies web platform.

## Directory Structure
- `pages/`: Page-level views and EJS templates (mapped to `/views`).
- `components/`: Modular reusable partials (`header.ejs`, `footer.ejs`, `head.ejs`).
- `styles/`: Core CSS design systems (mapped to `/public/css/style.css` and `/public/css/cms-v2.css`).
- `scripts/`: Client-side JavaScript bundles (`/public/js/main.js`, `/public/js/live-seo.js`).
- `assets/`: Static icons, SVG schematics, and brand identity assets (`/public/images`).

## Design System Guidelines
- **Palette**: Deep Obsidian Charcoal (`#070A0F`, `#0E131F`, `#141B2D`), Metallic Platinum Silver (`#E2E8F0`, `#CBD5E1`), and Radiant Saffron Gold (`#F59E0B`, `#FBBF24`, `#D97706`).
- **Typography**: Inter / Plus Jakarta Sans with JetBrains Mono for technical specifications.
- **Responsive Breakpoints**: Mobile (320px–480px), Phablet (481px–768px), Tablet (769px–991px), Desktop (992px–1280px), Large Display (1281px+).
